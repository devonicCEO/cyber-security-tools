# Güvenlik Politikası

## ⚠️ Yasal Sorumluluk

Bu araç **kendi sisteminiz veya yazılı izniniz olduğu sistemler için** eğitim amaçlı geliştirilmiştir.

**YASAL UYARI:**

- Başka bir kişinin veya kuruluşun bilgisayar sistemini izinsiz taramak **YASAL DEĞILDIR**
- Ruhsatsız port taraması birçok ülkede **siber suç** sayılır
- İhlal edilen kişiler veya şirketler yasal işlem başlatabilir

## Etik Kullanım

✅ **İzin verilen kullanım:**

- Kendi bilgisayarınız veya ağınız üzerinde test
- Yazılı izin aldığınız sistemlerde güvenlik testi
- Eğitim ve öğrenme amaçları (izlenen ortamlarda)
- Profesyonel penetrasyon testi (uygun sertifikalar ve sözleşmeler ile)

❌ **Yasak kullanım:**

- İzinsiz sistemlere erişim denemesi
- Diğer ağlara yetkisiz tarama
- İlgili kişi/şirketleri bilgilendirmeden hassas verileri tarama
- Suç amaçları için kullanım

## Raporlama

Eğer kodda bir güvenlik açığı bulursanız:

1. **Lütfen herkese açık bir issue açmayın**
2. Aşağıdaki adrese özel olarak rapor edin:
   - GitHub Security Advisory sistemini kullanın
   - veya güvenlik sorumlusuna e-posta gönderin

3. Raporda şunları içerin:
   - Açığın detaylı tanımı
   - Nasıl yeniden üreteceğiniz
   - Potansiyel etkileri

4. En az 90 gün izin verin ki fix'i hazırlayalım

## Sistem Güvenliği Tavsiyesi

Her ne kadar bu araç taraması yapılacak sistem için tasarlanmış olsa da:

- 🔒 Güvenlik duvarı kullanın
- 🔐 SSH için güçlü parolalar ayarlayın
- 🚫 Gereksiz portları kapatın/devre dışı bırakın
- 🔄 Işletim sisteminizi ve yazılımlarınızı güncel tutun
- 📝 Ağ trafiğini izleyin

## Eğitim Kaynakları

Siber güvenlik hakkında daha fazla bilgi:

- OWASP (Open Web Application Security Project)
- CEH (Certified Ethical Hacker) sertifikası
- HackTheBox, TryHackMe gibi platformlar
- Yerel siber güvenlik toplulukları

## İletişim

Güvenlik ile ilgili sorularınız için lütfen issue açınız.
