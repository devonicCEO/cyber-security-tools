# Katkıda Bulunma Rehberi

Projeye katkı sağlamak istediğiniz için teşekkür ederiz!

## Katkı Adımları

1. **Repoyu Fork Yapın**
   - GitHub üzerinde "Fork" butonuna tıklayın

2. **Kendi Bilgisayarınızda Klonlayın**

   ```bash
   git clone https://github.com/devonicCEO/Port-Tarama.git
   cd Port-Tarama
   ```

3. **Yeni Branch Oluşturun**

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Değişiklikleri Yapın**
   - Kodunuzu yazın ve test edin
   - PEP 8 standartlarına uyun

5. **Değişiklikleri Commit Edin**

   ```bash
   git commit -m "Add: Yeni özellik açıklaması"
   ```

6. **Branch'e Push Yapın**

   ```bash
   git push origin feature/your-feature-name
   ```

7. **Pull Request Açın**
   - GitHub'da "New Pull Request" butonuna tıklayın
   - Değişikliğinizi açıkça tanımlayın

## Katkı Kuralları

✅ **İyi Uygulamalar**

- Anlaşılır ve açıklayıcı commit mesajları yazın
- Bir PR açmadan önce kodunuzu test edin
- Türkçe ve İngilizce yorum satırları yazarken tutarlı olun
- PEP 8 kod stiline uyun

❌ **Kaçınılması Gerekenler**

- Hatalı veya test edilmemiş kod göndermek
- Orijinal repository'de büyük değişiklik yapmadan önce issue açmak
- Sayısız dosyayı değiştiren PR'ler (küçük ve odaklı tutun)

## Hata Raporlama

Bir hata bulduysanız:

1. Benzer bir issue olup olmadığını kontrol edin
2. Yeni bir issue açın
3. Hatanın nasıl meydana geldiğini açıkça tanımlayın
4. Beklenen davranış ile gerçek davranışı belirtin

## Özellik İstekleri

Yeni bir özellik önermek istiyorsanız:

1. Issue açın ve "enhancement" etiketini kullanın
2. Özelliğin kullanım durumunu açıklayın
3. Taslak bir implementasyon önerin (opsiyonel)

## Sorular?

Sorularınız varsa issue açın veya PR'de yorum yapın!
